# Tacet Leads

Leadsystemet for Tacet, bygget til at blive brugt ved at tale med Claude, fra mobil, bærbar eller stationær.

Al logik og alle regler står i [`CLAUDE.md`](CLAUDE.md). Skrivestilen står i [`docs/skrivestil.md`](docs/skrivestil.md).

## Kom i gang

Åbn repoet i Claude Code og sig fx:

- *Hvor er vi med Tempur?*
- *Notér: Tempur, Kasper har budget fra januar*
- *Hvem skal jeg tage fat i mandag?*
- *Skriv til Kasper om en dato for AI-formiddagen*
- *Ryd op i pipelinen*

Kræver connectors til Supabase, Gmail og Google Kalender på claude.ai-kontoen.
